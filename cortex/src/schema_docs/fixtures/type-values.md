# Type Values

Canonical list of allowed values for the `type` frontmatter field. This field describes what kind of note it is, not what topic it covers (that is `domain`).

Regenerated by `sb cortex schema --render`; do not edit.

## Rules

- Every note must have exactly one type.
- Type describes form, not content. A YouTube video about football is `type: youtube`, `domain: football`.
- When unsure, use `note` as the default.
- New type values are added to `NoteType` in `vault/src/schema.rs`; update any Bases views that filter by type.

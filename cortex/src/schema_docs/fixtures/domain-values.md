## Rules

- Notes in `inbox/` do not require a domain. Domain is assigned during triage.
- Daily notes omit the `domain` field entirely. They are structural, not topical. Query them by `type: daily`.
- Entity hub notes in `entities/` omit `domain`, `origin`, and `status` by contract.
- When a note spans two domains, pick the primary one. Tags handle the secondary.
- New domain values are added to `Domain` in `vault/src/schema.rs`; this file and any Bases views follow from there.

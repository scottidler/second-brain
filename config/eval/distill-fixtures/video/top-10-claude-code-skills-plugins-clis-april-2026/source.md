This is a comprehensive guide from a Claude Code expert covering the top 10 plugins, skills, and CLI tools to install when starting with Claude Code in 2026. ###### Enumerated Points

The creator covers 10 essential Claude Code tools and plugins:

1. **Codex Plugin** - Enables OpenAI's Codex to perform adversarial code reviews of Claude's output, providing unbiased assessment of code quality.
2. **Obsidian + Obsidian Skills** - Creates a knowledge management system using markdown files with visual knowledge graphs for organizing large document collections.
3. **Auto Research** - Machine learning algorithm that automatically runs experiments to optimize programs, keeping improvements and discarding failures.
4. **Awesome Design MD** - Front-end design templates based on popular websites like Claude and Notion, providing structured design files instead of generic AI output.
5. **FireCrawl CLI** - Web scraping tool that bypasses anti-bot protections and returns data in structured formats optimized for LLMs.
6. **Playwright CLI** - Browser automation tool that creates Chrome instances for testing websites and form submissions using accessibility trees instead of expensive screenshots.
7. **Notebook LM Pine** - CLI tool connecting Claude Code to Google's Notebook LM for batch processing, slide generation, and analysis offloaded to Google servers.
8. **Skill Creator Skill** - Official plugin for creating custom skills with built-in benchmarking and A/B testing to measure performance improvements.
9. **Light RAG** - Open-source [[graphrag|graph RAG]] system for handling large document collections when Obsidian reaches its scale limitations.
10. **GWS (Google Workspace CLI)** - Connects Claude Code to entire Google suite including email, docs, and calendar with pre-built workflow skills.

###### Key Ideas

- **Adversarial validation prevents AI blind spots** - Large language models rarely criticize their own code, making external review tools like Codex essential for quality assurance.
- **Free alternatives often outperform paid MCP versions** - The Playwright CLI is both more effective and cheaper than the official Playwright MCP, showing that newer isn't always better.
- **Offloading analysis saves tokens** - Tools like Notebook LM Pine that leverage external processing power can dramatically reduce Claude Code usage costs while maintaining functionality.
- **Skills need measurement to be useful** - Without benchmarking capabilities, it's impossible to know if custom skills actually improve outputs versus baseline performance.
- **Scale determines tool choice** - Simple solutions like Obsidian work great until you hit thousands of documents, at which point dedicated RAG systems become necessary.
